# Portal Pals
Isometric 5-round coin-collecting board game vs. an AI opponent.

- Run locally: `npm install && npm run dev`
- Live site: https://stonedarknightx.github.io/portalpals/
- Deploys automatically from `main` via GitHub Actions (Settings > Pages > Source: GitHub Actions).
- Art lives in `public/images`. Always reference it with `asset('/images/...')` so it works under `/portalpals/`.
